Stop a line

Today: a browser confirm(). The body keeps the code's three facts: hidden from students, no new supervisor, data and subscriptions kept. Real subscriber count.

إيقاف خط الزرقا؟

لن يظهر الخط للطلاب في التطبيق، ولن يشترك فيه أحد جديد، ولا يمكن إسناده لمشرف جديد.المشتركون الحاليون (124 طالباً) يبقى اشتراكهم كما هو، وتبقى محطاته ورحلاته وسجلاته. يمكنك تشغيله مرة أخرى في أي وقت.

Reactivate a line

Today: one click, no confirmation. Asked because it puts the line on sale again.

تشغيل خط رأس البر؟

يعود الخط للظهور في التطبيق لطلاب جامعة دمياط والمعهد العالي للهندسة، بالاشتراكات المعروضة للبيع الآن. محطاته ورحلاته وأسعاره كما تركتها.

Delete a line nobody used

Allowed only when the line has no subscriptions, no boarding records and no archived revenue (delete_line). Stations, trips and supervisor assignments go with it.

حذف خط عزبة البرج نهائياً؟

يُحذف الخط مع محطاته الخمس ورحلاته الأربع. لا يمكن التراجع.لم يشترك فيه أحد، فلن يتأثر أي طالب.

Delete refused

The same server rule, shown before the request when the subscriber count is known and as the answer when the server refuses. Offers what the code suggests: stop it.

لا يمكن حذف خط الزرقا

للخط اشتراكات وسجلات ركوب سابقة (124 اشتراكاً سارياً)، وحذفه يضيّعها.إن أردت ألا يراه الطلاب فأوقفه: يختفي من التطبيق وتبقى سجلاته.
